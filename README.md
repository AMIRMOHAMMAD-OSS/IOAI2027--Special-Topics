# IOAI-2026-special-topicss

This repository provides the theoretical background and practical implementation of one-step generation using drift fields on a physics-informed Riemannian manifold for 3D molecular conformer refinement. It includes training and evaluation workflows and accompanies a lecture in Special Topics in AI for Life Sciences, presented at Iran’s National Artificial Intelligence Olympiad in winter 2026.
